## 配置与程序证据

1. 冻结布局把房间估为宽 5.8m、深 12.5m、高 2.9m。原始 `assumptions` 明确说相机未校准、横梁与侧门未建模；这些输入不能当作已验证真值。
2. 后区左岛架中心 x 从 −0.93m 移至 −1.13m，右岛架中心 x 为 0.99m；配置的本地深度分别为 0.78m 与 0.76m，架体转向 90°。按目标架体尺寸计算，中间净距约为 `0.99 − (−1.13) − 0.78/2 − 0.76/2 = 1.35m`。左移前约 1.15m。因此“缩窄左侧通道”的 −0.2m 移动，同时把中间通道扩大了 0.2m。此为配置推导，非实测净距，也未计突出商品。
3. v3 的尺寸覆盖恢复的是此前模型估计的 `target_dimensions_m`，没有新增照片对应点或相机校准。错误尺寸假设可能被更准确地执行，而不是更接近真实店铺。
4. 保存场景优化刻意保留原相机矩阵和焦距。这是回归保护，不是照片对齐保证；本店十个相机仍为估计参数。
5. 相对 visual v2，本店全机位平均结构分从 0.0225 降至 0.0147，SSIM 从 0.0082 降至 −0.0008。不能仅凭这些分数判定错误位置，但与本次人工复核方向一致。
